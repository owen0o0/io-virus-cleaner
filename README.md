# IO Virus Cleaner

WordPress 病毒和木马扫描清理插件。按文件名、内容特征和通用 WebShell 写法找出可疑文件，确认后可以一键隔离或删除。

最初是为清理 2026 年 9～10 月的一次入侵写的（PHP 木马、Linux 远控程序、提权文件），后来补上了常见 WebShell 的通用规则。

## 下载

**[下载最新版 Release](https://github.com/owen0o0/io-virus-cleaner/releases/latest)**，附件里的 `io-virus-cleaner-<版本>.zip` 就是插件包。

不要下载 GitHub 自动生成的「Source code」压缩包，它的顶层目录名不对，装上去会变成另一个插件。

## 安装和使用

1. 后台「插件 → 安装插件 → 上传插件」，选择下载的 zip，安装并启用。
2. 在「插件」列表该插件下方点「扫描」，或打开「工具 → 病毒清理」。
3. 点「开始扫描」，终端窗口会实时显示进度和命中的文件。
4. 看结果：红色是高可信，默认勾选；黄色是「可疑」，默认不勾选，先看内容再决定。
5. 勾选后选择「隔离」或「删除」。隔离的文件会移到 `wp-content/io-virus-quarantine/`，文件名加 `.txt`，不能再被执行；确认没问题后可以在页面里清空隔离区。
6. 处理完再扫一次，木马可能会互相复制。

## 功能

- **文件名和内容特征**：识别本次入侵的木马、远控、提权文件，也能识别常见 WebShell 的一句话后门、反弹 shell、图片里夹带 PHP 等写法。
- **整个 wwwroot**：可以一次扫描服务器上的多个站点，并支持排除目录。
- **实时扫描**：分步执行，不受 PHP 执行时间限制；优先用 SSE，不通会自动改用轮询。
- **结果带权限和属主**：删不掉的文件会标出来，并提示到服务器上用 SSH 手动删除。
- **核心文件校验**（可选）：和 WordPress 官方 MD5 对比，找出被改过的核心文件，以及 `wp-admin`、`wp-includes` 里多出的 PHP。结果只列出。
- **每天自动扫描**（可选）：WP-Cron 每天凌晨扫一次，有新的高可信命中时发邮件。只通知，不会自动删除。
- **命令行**：不受 `open_basedir` 限制，适合扫整个 `wwwroot`。

## 命令行

只列出结果，不删除、不隔离：

```
php /path/to/wp-content/plugins/io-virus-cleaner/cli.php --dir=/www/wwwroot
```

- 多个目录用逗号隔开；`--exclude=` 排除目录；`--core-check` 同时校验核心文件。
- 命中打到标准输出，进度和汇总打到标准错误；有高可信命中时退出码为 1。
- 装了 WP-CLI 的话也可以用 `wp io-vc scan --dir=/www/wwwroot --allow-root`。

宝塔默认开着「防跨站攻击」（`open_basedir`），网页里读不到本站以外的目录，扫整个 `wwwroot` 请用命令行。不要为了扫描一直关着它。

## 安全说明

- 只读文件，不执行可疑程序，不修改 `wp-config.php`、`.htaccess`、`.user.ini`。
- 扫描本身不联网。只有两处会请求外部：检查插件更新（GitHub），以及你主动勾选的核心文件校验（`api.wordpress.org`）。
- 隔离和删除只在你点击确认后执行；计划任务和核心校验都不会自动处理文件。

## 局限

- 通用规则只能抓写法直白的木马，多层混淆的变种可能漏掉。
- 不扫描 `vendor`、`node_modules`、`.git` 目录；`cache` 目录只检查 PHP 文件。
- 不检查数据库里的注入内容，也不能代替更换数据库密码、WordPress 密钥盐和用户密码。
- 看不到正在发生的网络连接。

## 更新

插件头里写了 `Update URI`，后台「插件」页会直接从 GitHub Releases 检查更新，点更新即可。下载的 zip 会先校验 `sha256`，对不上就不安装。

首次需要手动安装一次带这个功能的版本（1.2.2 或更高）。国内服务器访问 GitHub 可能较慢，更新失败时手动下载 zip 安装就行。
